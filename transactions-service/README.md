# Transactions Service 💸

Microservicio para el registro, edición, eliminación y categorización de movimientos financieros (gastos e ingresos).

## Responsabilidades
- Registro y mantenimiento de transacciones financieras.
- Asignación de categorías (alimentación, transporte, servicios, etc.) y etiquetas.
- Consultas y filtrado por fecha, categoría y tipo de movimiento.
- Publicación o notificación de nuevos gastos hacia otros servicios (e.g. presupuestos).
